# Домашнее задание №1

## Описание датасета
- **Тематика:** Каталог косметических и уходовых средств интернет-магазина «Золотое Яблоко» (Gold Apple).
- **Способ получения:** Данные собраны собственным парсером через внутреннее API / веб-каталог интернет-магазина.
- **Объем данных:** 11 992 строки (товара).
- **Количество признаков:** 20 признаков.
- **Формат:** CSV (разделитель запятая, UTF-8), исходный JSON также доступен.
- **Ссылка на скачивание датасета (Google Drive):**
  - [Скачать датасет (CSV)](https://drive.google.com/file/d/1TecBD2z_Ky-DlefZBNW-lCtKOGLzRj5B/view?usp=sharing)

## Структура признаков

| Признак | Тип | Описание |
| :--- | :--- | :--- |
| `item_id` | Идентификатор / Строка | Уникальный артикул товара в магазине |
| `name` | Текст | Название товара / линейки |
| `brand` | Категориальный | Бренд производителя (например, STYX, Clarins и др.) |
| `product_type` | Категориальный | Тип продукта (крем, сыворотка, тоник и т.д.) |
| `price_actual` | Числовой (int/float) | Актуальная цена со скидкой (в рублях) |
| `price_regular` | Числовой (int/float) | Базовая цена без скидки (в рублях) |
| `rating` | Числовой (float) | Средний рейтинг товара покупателями (от 1.0 до 5.0) |
| `reviews_count` | Числовой (int) | Количество отзывов на товар |
| `in_stock` | Булев (bool) | Наличие товара в продаже |
| `category_main` | Категориальный | Основной раздел каталога (например, «уход для лица») |
| `category_sub` | Категориальный | Подкатегория (например, «увлажнение и питание») |
| `target_area` | Категориальный / Текст | Область применения (лицо, тело, веки) |
| `purpose` | Текст / Список | Назначение (увлажнение, антивозрастной уход, питание) |
| `skin_type` | Категориальный | Рекомендуемый тип кожи |
| `target_audience` | Категориальный | Целевая аудитория (универсально, женский, мужской) |
| `volume` | Текст / Числовой | Заявленный объём/вес упаковки (например, «50 мл») |
| `application_time`| Категориальный | Время применения (дневной, ночной, в любое время) |
| `active_ingredient`| Текст | Основной действующий компонент |
| `country` | Текст | Страна происхождения / производства бренда |
| `url` | Ссылка | Прямая ссылка на карточку товара в магазине |

## Потенциал для анализа и ML
1. **Предобработка и очистка данных:**
   - Извлечение числового значения объёма из текстового поля `volume` (в миллилитры/граммы).
   - Очистка поля `country` от префикса «страна происхождения».
   - Заполнение пропусков в скидках и характеристиках.
2. **Аналитические задачи (EDA):**
   - Анализ распределения цен и скидок по брендам и категориям товаров.
   - Зависимость рейтинга и количества отзывов от ценового сегмента и страны-производителя.
3. **Задачи машинного обучения:**
   - Регрессия: предсказание реальной цены или величины скидки на основе характеристик товара.
   - Классификация: автоматическое определение категории или типа кожи по описанию/названию.
